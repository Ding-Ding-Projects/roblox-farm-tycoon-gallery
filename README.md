# Farm Tycoon Capture Gallery

Public visual gallery of 17 genuine Play-session captures: 14 visually inspected furnished interior overviews, 2 historical HUD views, and 1 earlier barn interior retained for context.

The gallery is a public presentation of development evidence. It does not claim that the game is complete, that the images are final art, or that the experience is photorealistic. The 14 current interior captures were recorded on September 18, 2026 and exclude desktop, editor, system, and personal surfaces.

The gallery is a standalone static site for GitHub Pages. Its source images are copied from the reviewed evidence set in the development repository; no place file or source code is published.
